# 📱 모바일 환경 특화 & AI 에이전트 Neovim (Blink Shell) 완벽 가이드

이 문서는 아이폰/아이패드의 Blink Shell 환경에서 **모바일에 딱 맞게 최적화된 Neovim 단축키**와, 강력한 대화형 AI인 **CodeCompanion**의 실전 활용법을 담고 있습니다. Obsidian에서 편하게 열어보고 참고하세요.

---

## 🚀 1. 터미널 및 기본 조작 가이드

터치 스크린의 한계를 최대한 극복하도록 세팅되어 있습니다.

| 기능 | 행동/단축키 | 원리와 팁 |
| --- | --- | --- |
| **터미널 진입/종료** | `./start_workspace.sh` | 백그라운드 서버(PDF 등)와 자동 연동되며 Mosh 끊김 방지 `tmux` 환경으로 들어감. 나올 때는 `exit`라고 입력하면 됨. |
| **명령 모드 복귀** (Esc) | (입력 중) **`jj`** 연속 입력 | 아이폰 스크린 하단의 Esc 키를 누르기 귀찮을 때, 글자를 치다가 `j`를 연속으로 두 번 다닥 누르면 바로 일반(Normal) 모드로 빠져나옵니다. |
| **화면 스크롤** | 화면 손가락 스와이프 | 마우스 설정이 켜져 있으므로, 아이폰 화면을 손가락으로 드래그하면 코드가 자연스럽게 위아래로 스크롤됩니다. |
| **파일 열기/저장** | 편집창 진입: `i` 누르기 <br> 나갈 때: `jj`<br> 저장하기: `:w` 엔터 | `:w`를 치고 엔터를 누르는 즉시 Mac 백그라운드의 Typst 컴파일러가 PDF를 저장/갱신합니다. |

## 🤖 2. Codeium (무료 기본 AI 자동완성)

글자를 칠 때 흐릿한 회색 글씨로 "다음에 칠 내용"을 미리 예측해서 띄워주는 기능입니다. CodeCompanion 채팅창과 별개로 작동합니다.

| 작업 | 단축키 | 설명 |
| --- | --- | --- |
| **추천 코드 수락** | **`<Tab>`** | 회색으로 뜬 코드가 마음에 들면 Tab 키를 한 번 누르세요. 텍스트로 확정됩니다. |
| **다른 추천 보기** | **`→` (오른쪽 화살표)** | AI가 제안한 첫 번째 코드가 별로라면 오른쪽 방향키를 눌러 다음 후보안을 볼 수 있습니다. |

## ✨ 3. CodeCompanion (Gemini 대화형 Agent 플러그인) 핵심 메뉴얼

이것이 진짜 핵심입니다. 코딩하면서 터미널을 떠나지 않고 Gemini와 대화하며, 내 문서를 바로바로 고치게 만들 수 있습니다.

### 💬 3-1. 일반 채팅 (Chat)
오른쪽에 챗봇 창을 가볍게 열고, 모르는 것을 묻는 기능입니다.
- **실행 단축키:** Normal 모드나 Visual 모드에서 **`스페이스바` + `a`** (빠르게 연달아 누르지 말고 리듬감 있게!)
- **결과:** 화면 오른쪽에 대화창이 열립니다.
- **활용 예시:**
    - *"Typst에서 행렬식을 어떻게 예쁘게 쓰지?"*
    - *"이 오류 메시지가 왜 나오는 거야?"*
- **참고 태그 (`#buffer`):** 채팅할 때 `@`나 `#`을 누르면 현재 열린 파일을 AI에게 참조시킬 수 있습니다. *(예: "내가 지금 짠 `#buffer` 코드에서 어색한 부분 찾아줘")*
- **닫기:** 다시 **`스페이스바` + `a`** 를 누르면 닫힙니다.

### 🛠️ 3-2. 인라인 에이전트 (Inline Agent) - "이 부분 고쳐줘"
이 기능은 단순히 텍스트만 주고받는 게 아니라 **AI가 내 코드를 스캔한 뒤, 해당 코드 덩어리를 직접 새 코드로 교체해주는 마법**입니다.

1. **블록 지정 (Visual Mode):**
    수정하거나 번역하고 싶은 부분을 드래그(마우스나 화면 터치, 혹은 `v` 누르고 방향키로 영역 지정)합니다.
2. **실행 단축키:**
    원하는 영역이 지정된 상태에서 **`스페이스바` + `c`** 를 누릅니다.
3. **명령 내리기:**
    화면 하단에 미니 프롬프트 입력창이 뜹니다. 이렇게 명령하세요:
    - *"이 수식 정렬 예쁘게 맞춰줘"*
    - *"이 문장을 좀 더 부드러운 학문적 톤으로 번역해줘"*
4. **diff 확인 후 적용:**
    명령을 전송하면 화면에 Git처럼 변경 사항(빨간색/초록색)이 표시됩니다.
    결과물을 수락하려면 **엔터키(Accept)**를 누르시면 됩니다! 문서에 영구 적용됩니다.

---

### 기타 유용한 팁 (Blink Shell)
- **손가락 두 개 탭:** 아이패드/아이폰 Blink 화면에서 두 손가락으로 가볍게 탭하면, **우클릭(Esc 기능 매핑됨 등)** 동작이 수행되는 경우가 많아 터미널 조작 시 유용합니다.
- **커서 이동 (수식 쓸 때):** 모바일에서 왼쪽/오른쪽으로 이동이 불편할 땐 터미널 키보드의 특수 방향키 행렬을 활용하는 것이 정신 건강에 좋습니다.
